- 日期：2026-08-22
- 模式：一次真实 LLM 对话语义提取 + 确定性事实/政策执行器 + Evidence Fusion

- 接口：OpenAI-compatible Responses API
- 数据：4 个固定合成退款案例
- Oracle 隔离：标准答案仅由评测器读取，未进入 Prompt、Skill、工具返回或业务数据库

## 结论与限制

本次评测证明真实 LLM 严格 JSON Schema 输出、并行专项执行、CaseState 投影和证据融合链路可以贯通。当前网关对极短业务 Prompt 的单次输入仍约为 4.7k Token，说明固定上下文开销较高；MVP 暂不把事实与政策查询重复包装成 LLM Agent，后续须通过同预算对照实验判断新增调用是否提升证据完整率。

4 个合成案例不能支持准确率或生产效果声明。下一阶段至少补足 20 个案例，其中包含独立人工编写的模糊对话、错误客服承诺、政策时间边界和证据缺失案例，并单独报告不同数据来源。
